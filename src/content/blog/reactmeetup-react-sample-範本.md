概述說明

採用 Academind 的 [React Crash Course for Beginners 2021](https://youtu.be/Dorf8i6lCuk) 影片中的範例，會實作出一個 Meetups 的網站，你可以在網站新增 Meetups 或是將其他的 Meetups 加入我的最愛當中。

基於以上教學範本，再添加自己的額外更新和新增的資料庫與區塊!

如何啟用這個範例

1.用VS CODE 打開到範例資料夾

2.在終端機(cmd)下 

```
npm install
```

指令，開始在資料夾下安裝npm

3.在終端機(cmd)下 

```
json-server --watch db.json
```

指令，會啟動一個簡易的資料庫後端JSON

4. 在終端機(cmd)下 

```
npm run start 
```

指令，會詢問是否要創立不同的port去啟動，選擇Y

4.啟用範本
