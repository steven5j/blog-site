概述：

資產管理公司主要經營 房屋物件代租代管委託售買賣，建立網站主要目的為將數千份的代租代管物件歸檔建立至網站上，也讓網站訪客可以很簡易的查詢到相關的案件物件 並與顧問聯繫溝通，同時建立顧問上傳物件系統功能，讓公司顧問自行上傳相關案件資訊，降低公司行政作業人員行政作業消耗。.

網址(可能已關閉)：[https://butler2020.tw/](https://butler2020.tw/)

簡介：

．成效：

將數千筆房屋物件上架以方便訪客查看，並且建立顧問回報系統功能
．擔任PM，程式開發，100%獨立開發完成專案

．專案主要內容：

- 使用.Net core MVC 和 微軟相關技術 Entity
Framework Core 、DI賴注入..等開發

- 網站整體架構規劃設計

- MS SQL資料庫系統架構設計與維運

- 租借雲空間架設
註：專案內容多屬公司機密，僅截取重要資訊
