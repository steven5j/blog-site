學習和考試起因

雲端技術是未來重要的科技技術之一，我任職的公司本身是雲端服務提供的公司，所以同時有要求 要考取此張證照當作考核目標。因為我本身是完全對雲端架構毫無經驗的，同時自己也是想利用此張證照正式學習雲端技術知識與培養雲端能力。

證照介紹

![](https://wordpress-1652732-6572997.cloudwaysapps.com/wp-content/uploads/2022/12/microsoft-certified-azure-administrator-associate.2.png)

能掌握主題知識，可以實作、管理及監視組織的 Microsoft Azure 環境，包括虛擬網路、儲存體、計算、身分識別、安全性和治理情況。

應試者熟悉作業系統、網路、伺服器和虛擬化。 此外，此角色的專業人員應該具備使用 PowerShell、Azure CLI、Azure 入口網站、Azure Resource Manager 範本 (ARM 範本)，以及 Microsoft Azure Active Directory (Azure AD) 的經驗，並略懂 Microsoft Entra。

管理 Azure 身份識別和治理 (15–20%)
實作和管理儲存體 (15-20%)
部署和管理 Azure 計算資源 (20–25%)
設定和管理虛擬網路 (20-25%)
監視和維護 Azure 資源 (10–15%)

[AZ-104: Microsoft Azure Administrator](https://learn.microsoft.com/zh-tw/certifications/exams/az-104)

Azure的證照有效期只有一年!?

「Azure的證照有效期只有一年!?」當我考完證照後很驚訝地喊了這句出來，後來網路上查了訊息後，原來 目前微軟的政策是「[Keep pace with technology](https://learn.microsoft.com/zh-tw/certifications/renew-your-microsoft-certification#changes-to-certification-expiration-policy)」，簡單說原因是現在科技與技術進步太快，所以只要是中階以上的證照，現在統一政策的有效期都只有一年，每一年都要進行續訂證照的考試，但是這個考試是 免費的、簡短的，在網站考試即可。

詳細可查看：[Keep pace with technology](https://learn.microsoft.com/zh-tw/certifications/renew-your-microsoft-certification#changes-to-certification-expiration-policy)

但我覺得這樣的方式其實比Aws好，因為這樣的方式確保開發人員技術的進步，同時又不用讓工程師又再花一大筆錢去續訂證照，但也有缺點，假如考到證照越多，每一年要準備的續訂考試就越多。其實也代表每年要花費滿多時間處理準備的。

證照未來應用領域

這張證照最主要的目的就是在於有系統性的認識Azure提供的各項服務與功能，並且在遇到對應的商業情境下，可以提供不同應對的Azure雲架構。

如果本身是工程師職業，擁有這張證照可以有明確的讓主管或雇主知道說你有Azure雲端架構這方面的能力。

準備方式

前後大概花費了四個月左右的時間準備學習，都是利用早上提早一至兩小時到公司的時間看相關證照內容，下班後留在公司一至三小時的時間閱讀進修準備的。

在考這張證照的時候，起初我並不是很清楚怎麼去準備這張證照的考試。一開始本來想直接看[Examtopics](https://www.examtopics.com/exams/microsoft/az-104/)上面的考古題，但發現很多不是很懂，而且許多答案不太正確，看了網友的解答，也沒有解開心中的疑惑。

後來決定購買Udemy的課程，有系統的學習相關的內容，看完相關視頻以後，也購買了模擬試題，Udemy上面有開設的AZ-104模擬試題，提供的題目與考古題類似，且提供的的解答比較正確，也更加的完整詳細。
